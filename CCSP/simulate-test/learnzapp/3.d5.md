```
TLS

Authentication
    └─ usually certificate / PKI
       X.509 + digital signature

Key agreement / establishment
    └─ TLS 1.3 normally (EC)DHE
       or PSK / PSK+(EC)DHE

Derived traffic/session keys
    └─ symmetric

Application traffic
    └─ symmetric AEAD encryption
```

##  硬背


- **Uptime**
    - Tier I = Basic Capacity
    - Tier II = Redundant Capacity Components
    - Tier III = Concurrently Maintainable
    - Tier IV = Fault Tolerant  
        Uptime 現行資料仍維持這四級。
- Uptime Tier-defined facilities 的 fuel baseline：**12 hours at N load**。這題雖然 trivia，但至少仍有 Uptime 原始來源支持。
- ASHRAE recommended A1–A4 temperature：**18–27°C**；因此 93°F 顯然過高。
- NIST / ISO / ITIL / COBIT / CIS Controls 是什麼
- ITIL = IT service management
- NAS vs SAN
- SLE = AV × EF
- risk treatment：avoid / mitigate / transfer/share / accept
- residual risk 最終必須被適當接受
- TLS application traffic 使用 symmetric keys
- X.509 / PKI / CA 基本 trust model
- centralized log timestamps / clock synchronization
