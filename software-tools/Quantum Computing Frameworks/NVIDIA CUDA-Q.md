# NVIDIA CUDA-Q

## Core Features
CUDA-Q is a unified platform designed for "Quantum-Centric Supercomputing." It provides seamless integration between quantum processors (QPUs) and classical CPUs/GPUs, enabling developers to orchestrate hybrid workflows.

## Primary Use Cases
High-Performance Computing (HPC) integration. It allows researchers and enterprises to run quantum code alongside GPU-accelerated classical operations, which is critical for reaching "Scientific Quantum Advantage" in complex physics and materials science problems.

## Getting Started / Instructional Guide
Get started with NVIDIA CUDA-Q by setting up an environment with a compatible NVIDIA GPU and the CUDA toolkit installed. Download and install the CUDA-Q compiler and libraries. You can write hybrid quantum-classical programs in C++ or Python, utilizing CUDA-Q's specific constructs to define quantum kernels and launch them alongside classical GPU code.
