| 名詞             | 對照/中文           | 白話定義                                   |
| -------------- | --------------- | -------------------------------------- |
| **emittance**  | 發射度／束流「發散度」指標   | **描述束流有多不平行、光斑有多散**；越小越像雷射，越好聚焦。       |
| **wiggler**    | 扭擺磁鐵／波蕩器（阻尼環用）  | **用磁場讓電子左右擺動並放光，把橫向亂動「輻射掉」來冷卻束流。**     |
| **klystron**   | 速調管（大功率 RF 放大器） | **把微波功率放大到很大，供應加速腔需要的 RF 能量。**         |
| **cryomodule** | 低溫模組            | **把超導腔、保冷、真空、管線整合成可拼裝的低溫機械單元。**        |
| **collimator** | 準直器／束流整形與清雜元件   | **像束流的「濾網與剪裁器」：切掉尾巴與雜粒子，避免灌進偵測器。**     |
| **luminosity** | 亮度（碰撞產率指標）      | **等於「每秒能產生多少次有用碰撞」的能力；亮度越高，越快等到罕見事件。** |
